# Black Gold Market identity

`black-gold-market.jpg` is an unchanged copy of the owner's original `avatar.jpg` logo. Preserve the full square artwork; do not crop it to a circle or replace it with a text-only symbol.

Display name: **BLACK GOLD MARKET**. Tagline: **Protect. Master. Grow.**

The shared lockup is defined in `scripts/branding.py` and styled by `assets/brand.css`. Brand names use `translate="no"` to preserve their spelling.

`python3 scripts/build-portal.py` applies branding after generating pages. External journal publishers should run `python3 scripts/branding.py` after adding articles and before committing. The external publishing machine is configured separately.
